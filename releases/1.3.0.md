New

AI usage
- A key can be given an endpoint and a model, and BrimDeck asks the provider once an hour on the hour whether it is limited and when the limit resets, instead of the reset time being typed in by hand. The schedules it computes are kept in step with what the provider says.
- Keys are shown as colored rings, green while there is headroom and red when the limit is reached, with the model's name in the middle and the expected reset time below. Press the ring to check now; a second press while a check runs is ignored.
- The service's own note about a limit is shown as a tooltip rather than as a line on the page.
- A new key has a "Test connection" button; a test that succeeds refreshes the ring and saves what it learned.

Calendar
- New Calendar page: a month grid on the left with the subscribed holidays marked on their dates, and the next few work meetings on the right. Holidays are red and weekend days blue.
- Press any day to read that day's meetings in the column beside the month, and press it again, press "All", or press the empty space in the column to come back to the list. The left and right arrow keys step the month as well as the arrows beside its name.
- How many entries the column holds is a setting, five by default (Settings > Calendar > Shown > List length).
- Work calendars are read over CalDAV (Feishu, DingTalk) or Exchange ActiveSync (WeCom). Every calendar of an account is read, not only the first the server lists.
- Holiday calendars are read as plain iCalendar subscriptions, needing no account; the mainland China holidays are on by default and other regions can be added (Settings > Calendar > Subscribed calendars).
- Stepping the month reads the subscriptions over the month being shown, so its days carry their marks.

Mail
- New Mail page: the recent mail of the configured mailboxes, newest first, with a verification code taken out of the body and shown in the row.
- Mail is read over IMAP with the mailbox opened read-only and the parts fetched with BODY.PEEK, so the panel never marks a message as read. Only the text parts are fetched, so an attachment is never downloaded.
- QQ, 163, 126, Tencent Exmail, iCloud, Gmail and any other IMAP server over TLS are supported; each has its own "Test connection" button.
- A mailbox can be added with "Add a mailbox", and its row can be removed again (Settings > Mail).

Messages
- The island can show an incoming-message banner for the chat applications it knows, with the application's name and its unread count.

Improvements
- Every page has its own on/off switch (Settings > Display).
- Calendar and mail have their own settings pages, reachable from the page switch.
- The settings file keeps the keys, the calendars and the mailboxes across an update: the secrets are kept in the platform's own encrypted store, and the settings file is normalized on load so a file written by an older build is read rather than discarded.
- The size of the panel can be locked (Settings > Appearance > Size), so a panel that has been sized and placed cannot be changed by a stray drag on the screen's edge.

新功能

AI 用量
- 密钥可以填写接口地址与模型，BrimDeck 会在每个整点向服务商确认一次是否已达上限、上限何时重置，不再需要手动填写重置时间；它推算出的重置计划会跟着服务商的说法走。
- 密钥以彩色圆环显示，余量充足时为绿色，达到上限时变为红色，中间是模型名称，下方是预计重置时间。点击圆环可以立即检测一次，检测进行中再次点击不会重复发起。
- 服务商返回的说明改为鼠标悬停时显示，不再占用页面一行。
- 新增密钥时有「测试连接」按钮，测试成功后圆环会刷新，结果也会保存。

日程
- 新增「日程」页：左侧是月历，订阅的节假目标在对应日期上；右侧是接下来的几条工作日程。节假日为红色，周末为蓝色。
- 点击任意一天，右侧就显示那天的日程；再点一次、点「全部」，或点右侧列的空白处，可以回到列表。除了标题旁的箭头，键盘左右方向键也可以翻月。
- 右侧显示多少条可以设置，默认 5 条（设置 > 日程 > 显示 > 列表条数）。
- 工作日程通过 CalDAV（飞书、钉钉）或 Exchange ActiveSync（企业微信）读取。一个账号下的所有日历都会读取，不只是服务器列出的第一个。
- 节假日日历以 iCalendar 订阅的方式读取，不需要账号；中国大陆节假日默认开启，也可以添加其他地区（设置 > 日程 > 订阅日历）。
- 翻月时会按所显示的月份读取订阅，所以那一个月里的日期都会带上标记。

邮件
- 新增「邮件」页：按时间倒序列出已配置邮箱的近期邮件，正文里的验证码会被取出来显示在行内。
- 邮件通过 IMAP 读取，邮箱以只读方式打开，正文分段用 BODY.PEEK 获取，所以面板不会把邮件标记为已读；只读取文本分段，附件不会被下载。
- 支持 QQ、163、126、腾讯企业邮、iCloud、Gmail，以及其他使用 TLS 的 IMAP 服务器；每个邮箱都有自己的「测试连接」按钮。
- 可以用「添加邮箱」新增邮箱，也可以移除某一行（设置 > 邮件）。

消息
- 岛可以显示已知聊天应用的来信提示，包含应用名称和未读数量。

改进
- 每个页面都有独立的开关（设置 > 显示）。
- 日程与邮件各有独立的设置页，从页面切换处即可进入。
- 密钥、日历和邮箱在更新后不会丢失：密钥存放在系统自带的加密存储里，设置文件在读取时会做规范化，旧版本写出的文件会被读取而不是丢弃。
- 面板尺寸可以锁定（设置 > 外观 > 尺寸），锁定后已经调好大小和位置的面板不会被屏幕边缘的误拖动改变。
